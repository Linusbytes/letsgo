The original website from AY25/26 team is of a WordPress Full-Site Editing (FSE) Theme:

It contains PHP files (functions.php, index.php), ACF field definitions (acf-json/), and block templates (templates/*.html).
It requires WordPress core, a PHP server, and a MySQL database to function and render all the dynamic pages (courses, jobs, blog posts, forms, etc.).

Every single page and asset from the live server had been downloaded, converted into static files with clean relative links, and pushed directly to this repository.
